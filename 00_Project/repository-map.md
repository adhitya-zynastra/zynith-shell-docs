# Repository Map

Paths are absolute and **VERIFIED** to exist on 2026‑09‑21. Annotations mark files this project actually changed
or depends on; the upstream tree is far larger than what is listed here.

## 2. Configuration

```
~/.config/niri/
├── config.kdl              ← 133 lines. Entry point; includes rice/*.kdl then noctalia.kdl (order matters)
├── config.kdl.save         ← 635 lines. The stock niri config as it was before Zynith (kept verbatim)
├── noctalia.kdl            ← 32 lines. GENERATED by Noctalia (palette colours). Must stay last.
└── rice/
    ├── animations.kdl      ← GENERATED by the shell from [shell.animation] (validated + atomic)
    ├── glass.kdl           ← GENERATED by the shell from [shell.glass]: niri's single blur node
    ├── binds.kdl           ← 200 lines. Keybindings ported from my Hyprland config
    └── rules.kdl           ← 146 lines. Window rules + layer rules (glass, blur, opacity, privacy)

~/.config/noctalia/
├── rice.toml               ← 276 lines. THE Zynith design layer. Hand-written, the main thing to edit.
└── lockscreen.toml         ← 179 lines. Lock screen composition.

~/.local/state/noctalia/
├── settings.toml           ← 10 KB. OWNED BY THE NOCTALIA GUI. Overrides everything above. Do not hand-edit.
├── state.toml, recently_used.json, usage_counts.json, screen_time.json   ← runtime state
```

## 4. Where the design actually lives

A reader looking for "why does it look like this" should read, in order:

1. `~/.config/noctalia/rice.toml` — bar clusters, panel geometry, OSD/notification placement, palette source
2. `~/.config/niri/rice/rules.kdl` — glass: per-app opacity, blur, corner radius, layer rules
3. `src/ui/style.h` — motion tiers and spacing constants
4. `~/.config/noctalia/lockscreen.toml` — lock screen composition
